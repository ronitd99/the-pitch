# The Pitch

A soccer blog covering tactics, transfers, match analysis, and football culture.

**Live:** [ronitd99.github.io/the-pitch](https://ronitd99.github.io/the-pitch/)

## Stack

- HTML / CSS / JavaScript
- Google Fonts (Inter, Playfair Display)
- Hosted on GitHub Pages

## Structure

```
├── index.html        Homepage
├── article.html      Article page
├── category.html     Category listing
├── about.html        About + contact
├── css/style.css     Styles
├── js/main.js        Article data + interactivity
├── robots.txt        SEO
└── sitemap.xml       Sitemap
```

## Run Locally

Open `index.html` in a browser. No build step needed.
